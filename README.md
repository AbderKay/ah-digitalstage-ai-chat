A web-based **AI FAQ assistant** for AH Digital Agadir. Visitors type a question and get an instant answer, powered by an **n8n** workflow that combines a **Google Sheets** knowledge base and the **Google Gemini** AI model. Common questions are also available as a static FAQ, and complex questions can be escalated to a human agent via **Telegram**.

> Built during an internship at **AH Digital** (Technopark Agadir). See the [Technical Report](#-technical-report) section below.

---

## ✨ Features

- **AI assistant (24/7)** — type any question and receive an instant, AI-generated answer.
- **Knowledge base lookup** — the n8n workflow first checks a Google Sheets FAQ before falling back to the AI model.
- **Static FAQ section** — frequently asked questions displayed as expandable cards.
- **Human escalation** — when the AI is unsure, the question is forwarded to a human agent through Telegram.
- **Graceful fallback** — a friendly message is shown if the assistant is temporarily unavailable.
- **Interaction logging** — questions and answers are recorded for follow-up and improvement.

## ⚙️ How It Works

1. The user submits a question from the web interface.
2. The question is sent (HTTP POST) to an **n8n webhook**.
3. n8n looks up the answer in a **Google Sheets** FAQ knowledge base.
4. If no direct match is found, **Google Gemini** generates an answer.
5. If the AI is not confident, the question is escalated to a human agent via **Telegram**.
6. The final answer is returned to the web interface and shown to the user.

## 🚀 Getting Started

### Prerequisites

- **Node.js 18+** and npm
- An **n8n** instance (cloud or self-hosted) running the FAQ workflow

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/AbderKay/ah-digitalstage-ai-chat.git
cd ah-digitalstage-ai-chat

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

The app runs at `http://localhost:8080`.

### Connecting the AI backend

The question is sent to an n8n webhook defined in `src/pages/Index.tsx`. It currently points to a **local** endpoint:

```
http://localhost:5678/webhook-test/faq-question
```

Because `localhost` is only reachable on your own machine, replace this with your **deployed** n8n webhook URL (for example an n8n Cloud production URL) before publishing the site — otherwise the AI answers won't work online. The static FAQ section works without any backend.

## 🌐 Deployment

This is a static Vite single-page app and can be deployed to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

```bash
npm run build   # outputs the dist/ folder
```

On Vercel, connect the GitHub repository and it will build and deploy automatically on each push. Remember to point the n8n webhook URL to your deployed n8n instance in the code before going live.
